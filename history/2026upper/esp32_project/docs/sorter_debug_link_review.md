# 分拣链路调试功能说明

本文档用于后续审查分拣调试链路的外部现象和可操作功能，不描述内部算法。

## 调试入口

调试功能集中在 UI 的系统页。底部点击 `SYS` 后进入分拣调试页面。

页面提供三种链路模式：

- `ETH`：以太网/串口模拟链路。接收上位机或串口输入的模拟识别结果、模拟传感器和模拟距离。
- `REAL`：真实传感器链路。使用板子上的分拣光电传感器和编码器输入驱动链路。
- `TIMED`：纯计时链路。关闭传感器输入，链路按设置的超时时间和安全延时运行。

页面同时提供电机输出开关和传感器输入开关。关闭电机输出后，链路仍会产生控制命令，但不会下发真实电机动作。关闭传感器输入后，真实传感器不参与分拣推进，系统使用计时行为。

## 可调参数

系统页可调整以下参数：

- 三个电机速度：`A-`/`A+`、`B-`/`B+`、`C-`/`C+`，每次调整 5%。
- 安全延时：`-S`/`+S`，每次调整 100 ms。
- 三条传送带超时时间：`A-`/`A+`、`B-`/`B+`、`C-`/`C+`，每次调整 250 ms。

默认超时时间为：

- A 带：2000 ms
- B 带：750 ms
- C 带：750 ms

当传感器信号没有按预期出现时，链路会按对应传送带的超时时间继续处理，避免一直等待。

## 模拟分类按钮

系统页提供 `CLASS1`、`CLASS2`、`CLASS3`、`FREE`、`ERROR` 按钮。

按下后，系统表现为识别到对应类型的包裹，并输出该类型对应的电机控制动作。该功能用于不依赖摄像头和上位机时快速确认分拣动作是否符合预期。

## 硬件调试功能

### 电机测试

点击 `MTEST` 后，三个电机会依次正转：

- M1 正转 0.5 s 后停止
- M2 正转 0.5 s 后停止
- M3 正转 0.5 s 后停止

测试速度使用当前 UI 中设置的 A/B/C 电机速度。正反转极性由 `components/bsp/include/sorter_debug_config.h` 中的电机方向宏控制。

如果某个电机没有动作，优先检查：

- UI 中 `MOTOR` 是否为开启状态
- `sorter_debug_config.h` 中电机 GPIO 是否仍为 `-1`
- 电机接线、电源和驱动使能
- 对应电机方向反转宏是否符合实际接线

### 传感器状态

页面显示 `S2`、`S3`、`S4` 的触发状态：

- `ON`：当前稳定状态为触发
- `OFF`：当前稳定状态为未触发
- `--`：该传感器未配置或读取不可用

传感器触发极性由 `sorter_debug_config.h` 中的光电传感器极性宏控制。

### 编码器距离

页面显示 A/B/C 三路编码器累计距离，单位为 mm。每一路旁边都有 `CLR` 按钮，可单独清空该路距离。

如果距离不变化，优先检查：

- 编码器 A/B 相 GPIO 配置
- 编码器电源和信号线
- 方向反转宏是否符合实际安装方向
- UI 是否刚刚清空了对应距离

## 串口调试命令

USB 串口调试入口启动后会打印 `SORTDBG ready`。

常用命令：

- `help` 或 `HELP`：查看可用命令
- `test1`、`test2`、`test3`：快速模拟三类包裹
- `MOTOR_TEST`：执行三电机依次 0.5 s 测试
- `HW_STATUS`：输出传感器触发状态、编码器距离和电机测试状态
- `ENC_CLEAR index=0`：清空 A 路编码器距离，`index=1` 清空 B 路，`index=2` 清空 C 路
- `CONFIG mode=ethernet|real|timed ...`：调整调试模式和参数

## 审查观察点

审查时建议按以下现象确认：

1. 切到 `ETH` 后，模拟分类按钮和上位机模拟输入能触发对应电机控制。
2. 切到 `REAL` 后，遮挡 S2/S3/S4 时，UI 状态会在 `ON`/`OFF` 之间变化。
3. 切到 `TIMED` 或关闭 `SENSOR` 后，链路不依赖传感器触发，按超时时间继续推进。
4. 点击 `MTEST` 后，三个电机按 M1、M2、M3 的顺序依次短转。
5. 转动任意编码器后，对应距离显示增加；点击该路 `CLR` 后距离归零。
