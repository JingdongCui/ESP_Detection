## 4. 当前代码状态与最终作品状态差异

最近一次 ESP32P4_Detection 任务将硬件分拣启动停用，用于调试性能监视和上位机链路：

- 不再调用 `sorting_sim_debug_start()`。
- 不再启用电机输出。
- 不再启用真实传感器输入。
- Ethernet、图像链路、metrics 链路保留。

因此，正式比赛报告若描述“自动分拣闭环”，需要确认最终演示固件是否已经恢复硬件分拣启动，或是否另有正式演示版本。后续插板子后需要确定：

1. 最终使用哪个 ESP 固件提交。
2. 是否需要恢复真实电机和传感器输入。
3. 是否需要保留上电自动启动分拣。
4. 上位机是否能同时接收 metrics 和图像。
