## 2. 作品整体定位

- 暂定作品类型：智能物流包裹视觉识别与自动分拣系统。
- 核心目标：使用 ESP32-P4 在边缘端完成图像采集、目标检测、分拣决策和电机控制，上位机负责监控、图像留存、性能遥测和现场控制。
- 目标分类：极兔、韵达、中通三类快递包裹。
- 系统价值：面向物流分拣、自动化产线。

建议后续正式作品名称从以下方向中确定：

- 基于 ESP32-P4 的边缘智能物流分拣系统
- 嵌入式视觉快递包裹识别与分拣系统
- 面向物流场景的低延迟边缘视觉分拣平台

## 3. 系统组成

系统可按四层描述：

| 层级 | 组成 | 作用 |
| --- | --- | --- |
| 感知层 | SC2336 MIPI 摄像头、E18-D80NK 光电传感器 | 获取包裹图像和到位信号 |
| 边缘计算层 | ESP32-P4、ESP-DL 模型、LVGL UI、分拣调度程序 | 完成视觉识别、结果融合、状态显示和实时控制 |
| 执行层 | 三路传送带、电机驱动板、12V 直流减速电机、电源模块 | 按分类结果输送和分流包裹 |
| 上位机层 | Qt 6 桌面上位机、以太网 TCP 双链路 | 接收遥测和图像，保存记录，下发控制命令 |

推荐系统框图文字流：

```text
包裹进入主传送带
  -> 光电传感器触发包裹窗口
  -> SC2336 摄像头采集图像
  -> ESP32-P4 运行面单检测模型
  -> 第一阶段找面单 后运行 第二阶段Logo 三分类模型
  -> 分拣调度器根据分类和时序控制 A/B/C 电机
  -> 上位机通过以太网接收图像、遥测和分拣状态
```

### 5.2 视觉识别流程

当前视觉算法是两级级联：

1. 第一级：面单检测模型 `waybill.espdl` 在整图上检测面单区域。
2. 第二级：从面单区域裁剪 ROI，使用 `logo.espdl` 检测快递 Logo。
3. Logo 模型三分类：0=极兔、1=韵达、2=中通。
4. 识别结果映射到分拣分类，进入调度器。

模型与阈值信息：

| 模型 | 文件 | 默认阈值 | 作用 |
| --- | --- | --- | --- |
| 面单检测 | `waybill.espdl` | 0.85 | 从整图定位面单 |
| Logo 检测 | `logo.espdl` | 0.60 | 在面单 ROI 内识别快递公司 |

模型训练与部署补充：

- 训练集规模：约 5000 张图片。
- 训练优化：围绕真实包裹角度、光照、尺度、遮挡等情况调整数据增强。
- 部署优化：改进量化方式，降低模型压缩部署到 ESP32-P4 后的精度损失。
- 报告口径：突出“YOLO 轻量化部署优化”和“低延迟边缘推理”。

### 5.4 以太网与上位机通信

当前板端和上位机采用固定 IP 双 TCP 链路：

| 项目 | 值 |
| --- | --- |
| PC 上位机 IP | `192.168.10.1/24` |
| ESP32-P4 IP | `192.168.10.2` |
| control 端口 | `5000/tcp` |
| image 端口 | `5001/tcp` |
| metrics 周期 | 1 秒 |
| 图像格式 | JPEG |
| 图像快照尺寸 | `640 x 375` |
| JPEG 质量 | 85 |

链路分工：

- control 链路：遥测、时间同步、控制命令、分拣状态。
- image 链路：JPEG 图像快照。
- 采用固定 40 字节包头，包含 magic、version、type、seq、timestamp、payload length、图像宽高和像素格式。

## 6. 上位机资料

当前上位机工程：`esp32_host_no_inference`。

### 6.1 定位

上位机是基于 Qt 6 的桌面应用，不在 PC 端做模型推理。它作为整套系统的数据中心和控制台，负责：

- 监听 ESP32-P4 的 control/image 两路 TCP 连接。
- 实时展示板端 CPU、内存、PSRAM、图像链路状态。
- 接收和展示识别图片。
- 保存图片、遥测 JSONL 和包裹历史。
- 下发时间同步和电机速度配置。

### 6.2 软件分层

| 层级 | 模块 | 作用 |
| --- | --- | --- |
| UI 层 | QML 页面 | Dashboard、视觉检测、设备控制、系统维护 |
| 状态适配层 | `HostController` | 向 QML 暴露状态、图像 URL、遥测指标、控制接口 |
| 网络层 | `HostNetworkWorker` | 独立线程监听 control/image TCP |
| 协议层 | `packetprotocol` | 解析和生成二进制 packet |
| 数据层 | Documents/ESP32Host | 保存图片、遥测和日志 |

### 6.3 上位机报告亮点

- 控制链路与图像链路分离，避免大图像阻塞遥测和控制。
- 网络 I/O 在独立线程中运行，避免 UI 卡顿。
- 自定义 packet 解决 TCP 粘包、断包和图像元数据携带问题。
- 图像、包裹记录和遥测可本地留存，方便赛后复盘。
- 控制命令有去重和节流，适合现场调参。

## 10. 正式报告建议主线

建议把作品主线写成“低延迟嵌入式边缘 AI 分拣平台”：

1. 需求：传统分拣依赖人工识别，成本高且稳定性受人为因素影响。
2. 方案：ESP32-P4 边缘端完成识别与控制，避免依赖高性能 PC 推理。
3. 硬件：摄像头、光电传感器、三路传送带和模块化电源/驱动构成完整闭环。
4. 软件：两级级联视觉模型、分拣调度状态机、以太网双链路和 Qt 上位机。
5. 成果：在良好光照下实现三类包裹自动识别与分拣，速度超过 20 件/分钟，正确率记录超过 95%。置信度80% 
6. 扩展：可扩展更多快递类别、加入更稳定的光源、增加编码器闭环、设计专用 PCB、部署更完整的数据统计。
